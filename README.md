# Zubair Mustafa — Academic & Professional Portfolio

A responsive single-page portfolio built with HTML, CSS and vanilla JavaScript. No build step or framework is required.

## Run locally in VS Code

1. Extract the latest `Zubair_Mustafa_Portfolio_Updated_v6.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose this folder.
4. Install the **Live Server** extension (Ritwick Dey).
5. Open `index.html`, right-click, and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Files

- `index.html` — page structure and content
- `style.css` — visual design, responsive layout, themes and transitions
- `script.js` — navigation, filtering, theme persistence, image previews, scroll reveals and contact form validation
- `assets/` — photographs, logos, screenshots, certificates, research notice, favicon and CV

## Contact form

The contact form uses `mailto:`. It validates the fields and opens the visitor's default email application with the recipient, subject and message prefilled.

Recipient: `zubairmustafa321@gmail.com`

The visitor must press Send in their email application. This does not silently transmit messages from the website; a mail app or configured email client is required.

## CV

The uploaded CV is stored at `assets/Zubair_Mustafa_CV.pdf`. The Download CV buttons point to this file. Replace this file with a newer CV using the same filename when needed.

## Deploy

This is a static website. Upload the complete folder to Netlify, Vercel, GitHub Pages or another static host. Keep the folder structure intact so local assets load correctly.
