# Zubair Mustafa — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript. No frameworks or build tools required.

## Getting Started

1. Extract the latest portfolio ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in your browser.

## Project Structure

- `index.html` — Page content and structure
- `style.css` — Styling, themes and responsive design
- `script.js` — Navigation, animations, filtering and interactions
- `assets/` — Images, logos, certificates, CV and other resources
